# python-library-manager
A CRUD-focused Python CLI application for inventory management. It demonstrates nested data structures, list and dictionary state manipulation, member record management, and borrowing/return transaction workflows.

## 🔑 Key Features 
- **Book Inventory Management:** Add, update, view, and search catalog items.
- **Member Tracking:** Maintain member records and track active checkouts.
- **Borrowing Workflow:** Process checkouts and returns with status validation.
- **Interactive CLI:** Menu-driven interface handling user input and basic error edge cases.

## 🧩 Concepts Learned
- **CRUD Logic:** Implementing foundational data lifecycle operations.
- **Data Structures:** Working with dictionaries and nested lists for structured record storage.
- **Control Flow & Validation:** Validating inputs within a persistent application loop.
